29.7. シーケンスのレプリケーション #

《機械翻訳》パブリッシャーからサブスクライバーにシーケンスを同期化するには、まずCREATE PUBLICATION ... FOR ALL SEQUENCESを使用してシーケンスをパブリッシュ化し、次にサブスクライバーでを使用します。

  • 《機械翻訳》デフォルトから初期コピー値にシーケンスを引くには、copy_data = true（デフォルト）を使用して、パブリッシャーから初期シーケンス値をコピーするようにし、CREATE SUBSCRIPTIONを使用します。

  • 《機械翻訳》ALTER SUBSCRIPTION ... REFRESH PUBLICATIONを使用して、新しく追加されたシーケンスだけを同期させます。

  • 《機械翻訳》ALTER SUBSCRIPTION ... REFRESH SEQUENCES を使用して、そのサブスクリプションで現在認識されているすべてのシーケンスを再同期します。

《機械翻訳》Aシーケンス同期化ワーカーは、上記のサブスクライバーコマンドのいずれかを実行した後に開始され、シーケンスが同期化されると終了します。

《機械翻訳》シーケンス同期化ワーカーを起動する機能は、max_sync_workers_per_subscription設定によって制限されます。

注記

《機械翻訳》シーケンスの同期化には、パブリッシャーが実行されている必要がありますPostgreSQL19以降。

29.7.1. Sequence Definition Mismatches #

《機械翻訳》シーケンス同期化ワーカーは、そのシーケンス定義がパブリッシャーとサブスクライバーの間のマッチにあることを検証します。 不一致が存在する場合、ワーカーは不一致を識別するエラーを記録して終了します。 適用ワーカーは、同期化が成功するまでシーケンス同期化ワーカーの再生成を続行します。 wal_retrieve_retry_intervalも参照してください。

《機械翻訳》この問題を解決するには、ALTER SEQUENCEを使用して、サブスクライバーのシーケンスパラメータをパブリッシャーの標高と揃えます。

29.7.2. 《機械翻訳》同期していないシーケンスの更新。 #

《機械翻訳》サブスクライバーシーケンスの価値は、パブリッシャーが前進するにつれて同期しなくなる。

《機械翻訳》これを検出するには、サブスクリプション上のpg_subscription_rel.srsublsnを、ページ上のシーケンスのpg_get_sequence_data関数から得られたpage_lsnと比較してください。 その後、必要に応じてALTER SUBSCRIPTION ... REFRESH SEQUENCESを実行して再同期します。

警告

《機械翻訳》各シーケンスは、新しいWALブロックを生成するメモリ前に値のレコード（通常は32）をキャッシュするため、そのLSNは、キャッシュされたバッチ全体が消費された後にのみ先に進みます。 その結果、シーケンスの増分が同じキャッシュされた比較（通常は32の値）内にある場合、シーケンスの値のドリフトはLSNブロックによって検出できません。

29.7.3. 例 #

《マッチ度[66.666667]》パブリッシャーでいくつかテストテーブルを作成します。 《機械翻訳》パブリッシャーにいくつかのシーケンスを作成します。 

/* pub # */ CREATE SEQUENCE s1 START WITH 10 INCREMENT BY 1;
/* pub # */ CREATE SEQUENCE s2 START WITH 100 INCREMENT BY 10;

《マッチ度[77.272727]》サブスクライバー上に同じテーブルを作成します。 《機械翻訳》サブスクライバーにも同じシーケンスを作成します。 

/* sub # */ CREATE SEQUENCE s1 START WITH 10 INCREMENT BY 1;
/* sub # */ CREATE SEQUENCE s2 START WITH 100 INCREMENT BY 10;

《機械翻訳》パブリッシャーでのシーケンスを数回進めます。 

/* pub # */ SELECT nextval('s1');
 nextval
---------
      10
(1 row)
/* pub # */ SELECT nextval('s1');
 nextval
---------
      11
(1 row)
/* pub # */ SELECT nextval('s2');
 nextval
---------
     100
(1 row)
/* pub # */ SELECT nextval('s2');
 nextval
---------
     110
(1 row)

《マッチ度[50.000000]》パブリッシャーでいくつかテストテーブルを作成します。 《機械翻訳》チェックシーケンスページパブリッシャーのLSN。 

/* pub # */ SELECT * FROM pg_get_sequence_data('s1');
 last_value | is_called |  page_lsn
------------+-----------+------------
         11 | t         | 0/0178F9E0
(1 row)
/* pub # */ SELECT * FROM pg_get_sequence_data('s2');
 last_value | is_called |  page_lsn
------------+-----------+------------
        110 | t         | 0/0178FAB0
(1 row)

《機械翻訳》シーケンス用のパブリケーションを作成します。 

/* pub # */ CREATE PUBLICATION pub1 FOR ALL SEQUENCES;

《機械翻訳》サブスクライブからパブリケーション。 

/* sub # */ CREATE SUBSCRIPTION sub1
/* sub - */ CONNECTION 'host=localhost dbname=test_pub application_name=sub1'
/* sub - */ PUBLICATION pub1;

《機械翻訳》シーケンスの初期値が同期していることを確認します。 

/* sub # */ SELECT last_value, is_called FROM s1;
 last_value | is_called
------------+-----------
         11 | t
(1 row)

/* sub # */ SELECT last_value, is_called FROM s2;
 last_value | is_called
------------+-----------
        110 | t
(1 row)

《機械翻訳》パブリッシャーのシーケンスページLSNがサブスクライバーに記録されていることを確認する。 

/* sub # */ SELECT srrelid::regclass, srsublsn FROM pg_subscription_rel;
 srrelid |  srsublsn
---------+------------
 s1      | 0/0178F9E0
 s2      | 0/0178FAB0
(2 rows)

《機械翻訳》パブリッシャーのシーケンスをさらに50回進めます。 

/* pub # */  SELECT nextval('s1') FROM generate_series(1,50);
/* pub # */  SELECT nextval('s2') FROM generate_series(1,50);

《マッチ度[50.000000]》パブリッシャーでいくつかテストテーブルを作成します。 《機械翻訳》チェックシーケンスページパブリッシャーのLSN。 

/* pub # */ SELECT * FROM pg_get_sequence_data('s1');
 last_value | is_called |  page_lsn
------------+-----------+------------
         61 | t         | 0/017CED28
(1 row)

/* pub # */ SELECT * FROM pg_get_sequence_data('s2');
 last_value | is_called |  page_lsn
------------+-----------+------------
        610 | t         | 0/017CEDF8
(1 row)

《機械翻訳》パブリッシャーのシーケンスページLSNとサブスクライバーのシーケンスページLSN間の差は、シーケンスが同期していないことを示します。 ALTER SUBSCRIPTION ... REFRESH SEQUENCES を使用して、サブスクライバーが認識しているすべてのシーケンスを再同期します。 

/* sub # */ ALTER SUBSCRIPTION sub1 REFRESH SEQUENCES;

《マッチ度[62.500000]》サブスクライバー上に同じテーブルを作成します。 《機械翻訳》サブスクライバーのシーケンスをrecheckします。 

/* sub # */ SELECT last_value, is_called FROM s1;
 last_value | is_called
------------+-----------
         61 | t
(1 row)

/* sub # */ SELECT last_value, is_called FROM s2;
 last_value | is_called
------------+-----------
        610 | t
(1 row)
