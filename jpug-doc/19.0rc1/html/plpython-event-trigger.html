44.6. Event Trigger Functions #

<application>PL/Python</application> can be used to define event triggers (see also <xref linkend="event-triggers"/>). <productname>PostgreSQL</productname> requires that a function that is to be called as an event trigger must be declared as a function with no arguments and a return type of <literal>event_trigger</literal>. 《機械翻訳》PL/Pythonを使用してイベントトリガを定義できます（「第38章」も参照してください）。 PostgreSQLでは、関数として呼び出すイベントトリガは、引数なしの関数として宣言し、戻り値の型event_trigger.

When a function is used as an event trigger, the dictionary <literal>TD</literal> contains trigger-related values: 《マッチ度[88.596491]》トリガとして関数を使用した場合、TD辞書にトリガに関連した値が格納されます。 《機械翻訳》関数をイベントトリガとして使用する場合、ディクショナリTD包含トリガ関連の値:.

TD["event"]

The event the trigger was fired for, as a string, for example <literal>ddl_command_start</literal>. 《機械翻訳》トリガが焼かれたイベントは、例の文字列としてddl_command_start。

TD["tag"]

The command tag for which the trigger was fired, as a string, for example <literal>DROP TABLE</literal>. 《機械翻訳》トリガを焼いたコマンドタグは、例の文字列としてDROP TABLE。

<xref linkend="plpython-event-trigger-example"/> shows an example of an event trigger function in <application>PL/Python</application>. 《機械翻訳》例 44.1は、イベントトリガ関数の例を示しているPL/Python。

例44.1 A PL/Python Event Trigger Function

This example trigger simply raises a <literal>NOTICE</literal> message each time a supported command is executed. 《機械翻訳》この例トリガは、サポートされているメッセージが実行されるたびに、単純にNOTICEコマンドを上げる。 

CREATE OR REPLACE FUNCTION pysnitch() RETURNS event_trigger
LANGUAGE plpython3u
AS $$
  plpy.notice("TD[event] => " + TD["event"] + " ; TD[tag] => " + TD["tag"]);
$$;

CREATE EVENT TRIGGER pysnitch ON ddl_command_start EXECUTE FUNCTION pysnitch();
