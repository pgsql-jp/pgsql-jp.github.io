47.6. 《機械翻訳》ロジカルデコーディングアウトプットプラグイン #

<title>Logical Decoding Output Plugins</title>

<productname>PostgreSQL</productname> provides two logical decoding output plugins, <xref linkend="logicaldecoding-pgoutput"/> and <xref linkend="test-decoding"/>. You can also develop custom output plugins (see <xref linkend="logicaldecoding-output-plugin-writing"/> for details). 《機械翻訳》PostgreSQLには、pgoutputとtest_decodingという2つのロジカルデコーディングアウトプットプラグインが用意されています。 カスタムアウトプットプラグインを開発することもできます(詳細は47.7を参照してください。

47.6.1. 《機械翻訳》pgoutput—標準ロジカルデコーディングアウトプットプラグイン #

<title>pgoutput &mdash; Standard Logical Decoding Output Plugin</title>

<filename>pgoutput</filename> is the standard logical decoding output plugin provided by <productname>PostgreSQL</productname>. It's used for the built-in <link linkend="logical-replication"> logical replication</link>. 《機械翻訳》pgoutputは、PostgreSQL.で提供される標準的なロジカルデコーディングアウトプットプラグインです。 組み込み論理レプリケーションで使用されます。

47.6.1.1. オプション #

<title>Options</title>
proto_version (integer) #

Specifies the protocol version. Currently versions <literal>1</literal>, <literal>2</literal>, <literal>3</literal>, and <literal>4</literal> are supported. A valid version is required. 《機械翻訳》プロトコルバージョンを指定します。 現在のバージョンは1、2、3、および4がサポートされています。 有効なバージョンが必要です。

Version <literal>2</literal> is supported on server version 14 and above, and is required when <varname>streaming</varname> is set to <literal>on</literal> to stream large in-progress transactions. 《機械翻訳》バージョン2サーババージョン14以上でサポートされます。 また、ストリーミングがonストリームラージへの進行中のトランザクション。

Version <literal>3</literal> is supported on server version 15 and above, and is required when <varname>two_phase</varname> is enabled to stream two-phase commits. 《機械翻訳》バージョン3サーババージョン15以上でサポートされます。 また、ストリーム2フェーズコミットに対してtwo_phaseがイネーブルの場合に必要です。

Version <literal>4</literal> is supported on server version 16 and above, and is required when <varname>streaming</varname> is set to <literal>parallel</literal> to stream large in-progress transactions to be applied in parallel. 《機械翻訳》バージョン4サーババージョン16以降でサポートされます。 また、ストリーミングがparallelストリームラージに対して、進行中のトランザクションをパラレルで適用するに設定されている場合は必須です。

publication_names (string) #

A comma-separated list of publication names to subscribe to. The individual publication names are treated as standard objects names and can be quoted the same as needed. At least one publication name is required. 《機械翻訳》カンマで区切られたリストのパブリケーション名をサブスクライブ名に変換します。 個々のパブリケーション名は標準のオブジェクト名として扱われ、必要に応じて同じように引用符で囲むことができます。 少なくとも1つのパブリケーション名前が必要です。

binary (boolean) #

Enables binary transfer mode. Binary mode is faster than the text mode but slightly less robust. The default is <literal>off</literal>. 《機械翻訳》バイナリ振替モードを有効にします。 バイナリモードはテキストモードより高速ですが、安定性はわずかに劣ります。 デフォルトはoffです。

messages (boolean) #

Enables sending the messages that are written by <function><link linkend="pg-logical-emit-message">pg_logical_emit_message</link></function>. The default is <literal>off</literal>. 《機械翻訳》pg_logical_emit_messageによって書き込まれたメッセージの送信を有効にします。 デフォルトはoffです。

streaming (enum) #

Enables streaming of in-progress transactions. Valid values are <literal>off</literal> (the default), <literal>on</literal> and <literal>parallel</literal>. 《機械翻訳》進行中のトランザクションのストリーミングを使用可能にします。 有効な値は、off（デフォルト）、onおよびparallelです。

When set to <literal>off</literal>, <filename>pgoutput</filename> fully decodes a transaction before sending it as a whole. This mode works with any protocol version. 《機械翻訳》off,pgoutputに設定すると、トランザクションの前を完全にデコードし、そのまま送信します。 このモードはどのプロトコルバージョンでも動作します。

When set to <literal>on</literal>, <filename>pgoutput</filename> streams large in-progress transactions. This requires protocol version 2 or higher. 《機械翻訳》onに設定すると、pgoutputラージの進行中のトランザクションがストリームされます。 これにはプロトコルバージョン2以上が必要です。

When set to <literal>parallel</literal>, <filename>pgoutput</filename> streams large in-progress transactions and also sends extra information in some messages to support parallel processing. This requires protocol version 4 or higher. 《機械翻訳》parallelに設定すると、pgoutputラージの進行中のトランザクションがストリームされ、一部のメッセージに含まれる追加情報もサポートのパラレル処理に送信されます。 これにはプロトコルバージョン4以降が必要です。

two_phase (boolean) #

Enables sending two-phase transactions. Minimum protocol version 3 is required to turn it on. The default is <literal>off</literal>. 《機械翻訳》2フェーズ・トランザクションの送信を可能にします。 これをオンにするには、最小プロトコルバージョン3が必要です。 デフォルトはoffです。

origin (enum) #

Specifies whether to send changes by their origin. Possible values are <literal>none</literal> to only send the changes that have no origin associated, or <literal>any</literal> to send the changes regardless of their origin. This can be used to avoid loops (infinite replication of the same data) among replication nodes. The default is <literal>any</literal>. 《機械翻訳》変更をオリジン別に送信するかどうかを指定します。 有効な値は、noneオリジンが関連付けられていない変更のみを送信するまたはanyオリジンに関係なく変更を送信するです。 これは、レプリケーションノード間のループ（同じデータの無限レプリケーション）を回避するために使用できます。 デフォルトはanyです。

47.6.1.2. 注釈 #

<title>Notes</title>

<filename>pgoutput</filename> produces binary output, so functions expecting textual data ( <function><link linkend="pg-logical-slot-peek-changes">pg_logical_slot_peek_changes</link></function> and <function><link linkend="pg-logical-slot-get-changes">pg_logical_slot_get_changes</link></function>) cannot be used with it. Use <function><link linkend="pg-logical-slot-peek-binary-changes">pg_logical_slot_peek_binary_changes</link></function> or <function><link linkend="pg-logical-slot-get-binary-changes">pg_logical_slot_get_binary_changes</link></function> instead. 《機械翻訳》pgoutputはバイナリの出力を生成します。 したがって、テキストデータを想定した関数（pg_logical_slot_peek_changesおよびpg_logical_slot_get_changes）はこの関数と一緒に使用することはできません。 代わりにpg_logical_slot_peek_binary_changesまたはpg_logical_slot_get_binary_changesを使用してください。
