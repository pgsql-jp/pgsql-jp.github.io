53.19. pg_publication_sequences #

The view <structname>pg_publication_sequences</structname> provides information about the mapping between publications and sequences. 《マッチ度[57.142857]》pg_wait_eventsビューは、待機イベントに関する説明を提供します。 《機械翻訳》ビューpg_publication_sequencesパブリケーションとシーケンスの間のマッピングに関する情報を提供します。
