CHECKPOINT

CHECKPOINT <refpurpose>force a write-ahead log checkpoint</refpurpose> — 先行書き込みログ（WAL）のチェックポイントを強制的に実行する

概要

CHECKPOINT [ ( option [, ...] ) ]

where option can be one of:

    FLUSH_UNLOGGED [ boolean ]
    MODE { FAST | SPREAD }

説明

<title>Description</title>

A checkpoint is a point in the write-ahead log sequence at which all data files for permanent relations have been updated to reflect the information in the log. All data for permanent relation files will be flushed to disk. Dirty buffers of unlogged relations are not flushed unless <literal>FLUSH_UNLOGGED</literal> is specified. Refer to <xref linkend="wal-configuration"/> for more details about what happens during a checkpoint. 《マッチ度[61.574074]》《タグ不一致》チェックポイントとは、ログ内の情報を反映するために全てのデータファイルを更新する、先行書き込みログ（WAL）のある一時点を指します。 チェックポイントによって、全てのデータファイルがディスクに書き出されます。 チェックポイントの間に何が起きるかについては、28.5を参照してください。 《機械翻訳》チェックポイントは、先行書き込みポイント内のログシーケンスであり、ここで永続データのすべてのリレーションファイルが更新され、ログ内の情報が反映されます。 永続リレーションファイルのすべてのデータは、ディスクにフラッシュされます。 ログに記録されないリレーションのダーティバッファは、FLUSH_UNLOGGEDが指定されていない限り、フラッシュされません。 チェックポイント中の動作の詳細については、28.5を参照してください。

By default, the <command>CHECKPOINT</command> command forces a fast checkpoint when the command is issued, without waiting for a regular checkpoint scheduled by the system (controlled by the settings in <xref linkend="runtime-config-wal-checkpoints"/>). To request the checkpoint be spread over a longer interval, set the <literal>MODE</literal> option to <literal>SPREAD</literal>. <command>CHECKPOINT</command> is not intended for use during normal operation. 《マッチ度[65.509761]》《タグ不一致》CHECKPOINTコマンドは、コマンドが発行された時、（19.5.2によって制御される）システムによって予定された通常のチェックポイントを待たず、即座に強制的にチェックポイント処理を行います。 通常の運用時にCHECKPOINTが使用されることは想定していません。 《機械翻訳》デフォルトごとに、CHECKPOINTコマンドは、コマンドが発行されると、システムがスケジュールする定期チェックポイント（19.5.2の設定によって制御されます）を待たずに、高速チェックポイントを強制します。 チェックポイントをより長いインターバルにわたってリクエストするには、MODEオプションをSPREAD.CHECKPOINTに設定します。 これは、通常の操作での使用を目的としていません。

The server may consolidate concurrently requested checkpoints. Such consolidated requests will contain a combined set of options. For example, if one session requests a fast checkpoint and another requests a spread checkpoint, the server may combine those requests and perform one fast checkpoint. 《機械翻訳》サーバは、同時に要求されたチェックポイントを統合できます。 このような統合された要求には、オプションの組合せセットが含まれます。 例の場合、1つのセッションが高速チェックポイントを要求し、別のチェックポイントが拡張チェックポイントを要求すると、サーバはこれらの要求を結合して、1つの高速チェックポイントを実行できます。

If executed during recovery, the <command>CHECKPOINT</command> command will force a restartpoint (see <xref linkend="wal-configuration"/>) rather than writing a new checkpoint. リカバリ中に実行された場合、CHECKPOINTは新しくチェックポイントを書き出さずにリスタートポイント（28.5参照）を強制します。

Only superusers or users with the privileges of the <xref linkend="predefined-role-pg-checkpoint"/> role can call <command>CHECKPOINT</command>. CHECKPOINTを呼び出すことができるのは、スーパーユーザまたはpg_checkpointロールの権限を持つユーザのみです。

パラメータ

<title>Parameters</title>
FLUSH_UNLOGGED

Normally, <command>CHECKPOINT</command> does not flush dirty buffers of unlogged relations. This option, which is disabled by default, enables flushing unlogged relations to disk. 《機械翻訳》通常、CHECKPOINTは、ログに記録されていないダーティバッファのリレーションをフラッシュしません。 このオプションは、デフォルトによって無効にされていますが、ログに記録されていないリレーションをディスクにフラッシュすることを有効にします。

MODE

When set to <literal>FAST</literal>, which is the default, the requested checkpoint will be completed as fast as possible, which may result in a significantly higher rate of I/O during the checkpoint. 《機械翻訳》FASTデフォルトに設定すると、要求されたチェックポイントが可能な限り早く完了するため、レート中の入出力のチェックポイントが大幅に高くなる場合があります。

<literal>MODE</literal> can also be set to <literal>SPREAD</literal> to request the checkpoint be spread over a longer interval (controlled via the settings in <xref linkend="runtime-config-wal-checkpoints"/>), like a regular checkpoint scheduled by the system. This can reduce the rate of I/O during the checkpoint. 《機械翻訳》MODEまた、次のように設定することもできます。 SPREADリクエストに対して、チェックポイントはより長いインターバル（19.5.2の設定によって制御される）に広がります。 これは、システムによってスケジュールされた通常のチェックポイントのようなものです。 これにより、チェックポイント中の入出力のレートを減らすことができます。

boolean

Specifies whether the selected option should be turned on or off. You can write <literal>TRUE</literal>, <literal>ON</literal>, or <literal>1</literal> to enable the option, and <literal>FALSE</literal>, <literal>OFF</literal>, or <literal>0</literal> to disable it. The <replaceable class="parameter">boolean</replaceable> value can also be omitted, in which case <literal>TRUE</literal> is assumed. 《機械翻訳》選択したオプションをオンにするか、オフにするかを指定します。 TRUE、ON、または1と記述するとオプションが有効になり、FALSE、OFF、または0と記述すると無効になります。 ブールの値を省略することもでき、その場合はケースTRUEが想定されます。

互換性

<title>Compatibility</title>

The <command>CHECKPOINT</command> command is a <productname>PostgreSQL</productname> language extension. CHECKPOINTコマンドは、PostgreSQLの拡張です。
