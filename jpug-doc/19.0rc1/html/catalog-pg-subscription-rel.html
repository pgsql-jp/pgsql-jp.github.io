52.55. pg_subscription_rel #

The catalog <structname>pg_subscription_rel</structname> stores the state of each replicated table and sequence for each subscription. This is a many-to-many mapping. 《マッチ度[78.313253]》カタログpg_subscription_relには各サブスクリプションで複製される各リレーションの状態が入ります。 これは多対多のマッピングです。 《機械翻訳》カタログpg_subscription_relレプリケートされた各テーブルの状態と、各シーケンスのサブスクリプションを格納します。 これは多対多マッピングです。

This catalog contains tables and sequences known to the subscription after running: <link linkend="sql-createsubscription"><command>CREATE SUBSCRIPTION</command></link>, <link linkend="sql-altersubscription-params-refresh-publication"> <command>ALTER SUBSCRIPTION ... REFRESH PUBLICATION</command></link>, or <link linkend="sql-altersubscription-params-refresh-sequences"> <command>ALTER SUBSCRIPTION ... REFRESH SEQUENCES</command></link>. 《マッチ度[53.636364]》《タグ不一致》このカタログにはCREATE SUBSCRIPTIONあるいはALTER SUBSCRIPTION ... REFRESH PUBLICATIONを実行した後でサブスクリプションに知られることになったテーブルのみが含まれます。 《機械翻訳》CREATE SUBSCRIPTION, ALTER SUBSCRIPTION ... REFRESH PUBLICATION、またはALTER SUBSCRIPTION ... REFRESH SEQUENCESを実行した後に、カタログが認識している包含テーブルとシーケンス。

srsubstate char

State code for the table or sequence. 《機械翻訳》コードまたはシーケンスの場合、「State Region」と入力します。 テーブル

State codes for tables: <literal>i</literal> = initialize, <literal>d</literal> = data is being copied, <literal>f</literal> = finished table copy, <literal>s</literal> = synchronized, <literal>r</literal> = ready (normal replication) 《マッチ度[79.914530]》状態コード： i = 初期化、 d = データのコピー中、 f = テーブルコピーの完了、 s = 同期済み、 r = 準備完了（通常のレプリケーション） 《機械翻訳》テーブルの状態コード:i=初期化、d=データがコピーされている、f=終了したテーブルコピー、s=同期、r=準備完了（通常のレプリケーション）。

State codes for sequences: <literal>i</literal> = initialize, <literal>r</literal> = ready 《機械翻訳》シーケンスの状態コード:i=初期化、r=準備完了。

srsublsn pg_lsn

Remote LSN of the state change used for synchronization coordination when in <literal>s</literal> or <literal>r</literal> states, otherwise null. For sequences, this instead holds the publisher sequence's page LSN as of the last synchronization, which does not track replication progress the way it does for tables; see <xref linkend="sequences-out-of-sync"/> for how it is used to detect out-of-sync sequences. 《機械翻訳》同期の調整に使用される状態変更のリモートLSN sまたはr状態、それ以外の場合はNULL。 シーケンスの場合は、代わりに最後の同期の時点のパブリッシャーシーケンスのページLSNが保持されます。 これは、テーブルの場合とは異なり、レプリケーションの進行状況を追跡しません。 非同期シーケンスを検出するための使用方法については、29.7.2を参照してください。
