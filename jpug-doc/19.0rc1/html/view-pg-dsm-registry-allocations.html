53.8. pg_dsm_registry_allocations #

The <structname>pg_dsm_registry_allocations</structname> view shows shared memory allocations tracked in the dynamic shared memory (DSM) registry. This includes memory allocated by extensions using the mechanisms detailed in <xref linkend="xfunc-shared-addin-dynamic" />. 《機械翻訳》pg_dsm_registry_allocationsビューは、動的な共有メモリ(DSM)レジストリで追跡される共有メモリ割当てを示しています。 これには、36.10.11.3で説明されているメカニズムを使用して、拡張機能によって割り当てられたメモリも含まれます。

表53.8 pg_dsm_registry_allocations Columns

Column Type 列 型

Description 説明

name text

The name of the allocation in the DSM registry. 《機械翻訳》DSMレジストリのアロケーションの名前。

type text

The type of allocation. Possible values are <literal>segment</literal>, <literal>area</literal>, and <literal>hash</literal>, which correspond to dynamic shared memory segments, areas, and hash tables, respectively. 《機械翻訳》アロケーションのタイプ。 指定可能な値はsegment、areaおよびhashで、それぞれ動的な共有メモリセグメント、面積およびハッシュテーブルに対応します。

size int8

Size of the allocation in bytes. NULL for entries that failed initialization. 《機械翻訳》アロケーションのサイズ（バイト単位）。 初期設定に失敗したエントリのNULL。


By default, the <structname>pg_dsm_registry_allocations</structname> view can be read only by superusers or roles with privileges of the <literal>pg_read_all_stats</literal> role. 《マッチ度[89.385475]》デフォルトではpg_shmem_allocationsはスーパーユーザか、pg_read_all_statsロールの権限を持つロールだけが読み取りできます。 《機械翻訳》デフォルト別に見ると、pg_dsm_registry_allocationsビューは、スーパーユーザまたはpg_read_all_statsそのロールの権限を持つロールのみが読み取ることができます。
