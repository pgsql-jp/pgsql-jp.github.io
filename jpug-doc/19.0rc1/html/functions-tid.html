9.14. TID Functions #

<xref linkend="functions-tid-table"/> lists functions for the <type>tid</type> data type (tuple identifier). 《機械翻訳》表 9.45に、TIDデータタイプ（タプル識別子）の機能を示します。

表9.45 TID Functions

Function 関数

Description 説明

Example(s) 例

tid_block ( tid ) → bigint

Extracts the block number from a tuple identifier. 《機械翻訳》ブロック識別子からタプル番号を抽出します。

tid_block('(42,7)'::tid) → 42

tid_offset ( tid ) → integer

Extracts the tuple offset within the block from a tuple identifier. 《機械翻訳》タプルオフセットから、ブロック内のタプル識別子を抽出します。

tid_offset('(42,7)'::tid) → 7
